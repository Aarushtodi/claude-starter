# claude-starter

Claude Code setup for a high school student on a Pro plan: rules file, 5 school skills, hooks (notes index, safety guard, status line, call-out logger), Canvas alert scripts, school clock, bypass permissions as default.

1. Read `SETUP.md` top to bottom.
2. `git clone https://github.com/Aarushtodi/claude-starter.git ~/claude-starter && bash ~/claude-starter/install.sh`
3. Fill in ABOUT ME in `~/.claude/CLAUDE.md`, then run `claude` in `~/school`.

Or skip all of that: paste `BOOTSTRAP.md` into Claude as your first message and it does every step with you.

Files: `BOOTSTRAP.md` (the one paste setup), `EXTRAS.md` (catch-up paste for a session already running), `PHONE.md` (paste into the Claude app on your phone: Focus modes, Screen Time, done last), `OBSIDIAN.md` (standalone Obsidian walkthrough), `PLAYWRIGHT.md` (browser scripts, Playwright the library, not the MCP), `deca/` (DECA business plan kit: coach prompt + official 2026-27 PDFs, see deca/README.md), `COUNCIL.md` (decision council for the plain Claude app: put it in a Project called Council, one decision per chat), `CALENDAR.md` (Google Calendar runner for the plain Claude app: Project called Calendar, add / done / plan my week, Pro friendly), `SETUP.md` (manual version and reference), `CLAUDE.md` (the rules file), `install.sh`, `skills/`, `hooks/`, `bin/`, `vault/`.
