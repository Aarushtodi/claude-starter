# claude-starter

Claude Code setup for a high school student on a Pro plan: rules file, 5 school skills, hooks (notes index, safety guard, status line, call-out logger), Canvas alert scripts, school clock, bypass permissions as default.

1. Read `SETUP.md` top to bottom.
2. `git clone https://github.com/Aarushtodi/claude-starter.git ~/claude-starter && bash ~/claude-starter/install.sh`
3. Fill in ABOUT ME in `~/.claude/CLAUDE.md`, then run `claude` in `~/school`.
