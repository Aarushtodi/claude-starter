# DECA kit (Independent Business Plan, EIB)

Everything you need to write the paper with Claude. Paper is due at school Wed Nov 11.

## Set it up once (5 minutes)

1. Download the kit: https://github.com/Aarushtodi/claude-starter/releases/latest/download/deca-kit.zip
2. Right click the zip, Extract All.
3. Open the Claude app. Click Projects, then Create project. Name it DECA.
4. In the project, find the files / knowledge area and upload all 5 files from the folder.
5. In the project instructions box paste this line:
   `Follow "DECA coach prompt.md" in this project's files exactly. Start at Part 7, Stage 0.`
6. Start a new chat in the DECA project and type: start

Every work session: open a new chat in the DECA project and type "where are we" first.

## What's in it

| File | What it is |
|---|---|
| DECA coach prompt.md | The coach. Takes you through the paper one decision at a time, builds the financials with you, then judges you like a VC. |
| EIB official guidelines 2026-27.pdf | DECA's official event rules, outline and both scoring rubrics (from deca.org). |
| Penalty point checklist.pdf | The format rules that cost points. Run the paper against this before you print. |
| Statement of Assurances (you and advisor sign).pdf | Goes in front of the paper. Real or digital signatures from you AND the chapter advisor. Missing = 15 points off. |
| DECA sample EIB paper (format only, do not copy).pdf | DECA's own sample. Look at it for layout and level. Never copy wording or ideas. |
